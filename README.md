# pop-to-gmail

회사 POP3 메일함의 새 메일을 30분마다 Gmail 받은편지함으로 복사합니다. PC가 꺼져 있어도 GitHub Actions에서 돌아갑니다.

- 회사 서버 메일은 지우지 않습니다 (Outlook과 같이 써도 안전)
- 원본을 그대로 넣기 때문에 보낸 사람, 첨부, 날짜가 원본과 같습니다
- Gmail에 `회사메일` 라벨이 붙습니다
- 같은 메일은 두 번 넣지 않습니다 (Message-ID 기준)
- 로그에는 건수만 남습니다

## 설정 (Settings > Secrets and variables > Actions > New repository secret)

| 이름 | 값 |
|---|---|
| `POP_HOST` | 회사 메일 호스팅 서버 |
| `POP_PORT` | PORT입력 (비워두면 110) |
| `POP_USER` | 회사 메일 로그인 아이디 |
| `POP_PASS` | 회사 메일 비밀번호 |
| `GMAIL_USER` | 받을 Gmail 주소 |
| `GMAIL_APP_PASSWORD` | Gmail 앱 비밀번호 16자리 |

## 실행

- 자동: 30분마다
- 수동: Actions 탭 > `회사메일 → Gmail` > Run workflow
- 실패하면 GitHub가 알림 메일을 보냅니다

## 첫 실행

최근 48시간 메일만 가져옵니다 (`MAX_AGE_HOURS`로 조절). 그 이전 메일은 건너뜁니다.

## 환율 (CBR EUR → 환율!.xls)

매월 1~3일, 구글드라이브 `환율` 폴더의 `환율!.xls`에 지난달 러시아 중앙은행 EUR 일별 환율을 채웁니다.

- 주말, 공휴일은 직전 고시값 (기존 파일 방식과 같음)
- 이미 값이 있는 칸은 덮어쓰지 않음. CBR과 다르면 메일로 알림
- 엑셀, LibreOffice로 다시 저장하지 않고 해당 칸 숫자만 바꿈 (서식, 수식, 다른 시트 그대로). 수식은 엑셀에서 열 때 다시 계산
- 드라이브 버전 관리에 이전 버전이 남음
- 새 해 시트: 12월분을 채울 때(1월 1~3일) 전년 시트를 복사해 자동 생성 (날짜 +1년, 환율과 수기 숫자 비움, 수식 유지, 제목의 26Y → 27Y). 윤년(2028)은 날짜 칸 수가 달라 실패 메일 → 직접 생성

필요한 Secret: `GDRIVE_SA_JSON` (구글 서비스 계정 키 JSON 전체). 서비스 계정 이메일을 `환율` 폴더에 편집자로 공유.
수동 실행: Actions > `환율 (CBR EUR → 환율!.xls)` > Run workflow (달 입력 가능)

## 급여환율 (x-rates → 환율!.xls)

급여일(10일, 25일, 쉬는 날이면 직전 근무일)을 1일째로 세어 근무일 5일째가 기준일. 러시아 공휴일은 생산 달력(isdayoff.ru, 실패 시 xmlcalendar.ru)에서 매년 받음.
기준일 08:00부터 30분마다 12:00까지(칼리닌그라드) x-rates 월평균(전전달, 전달, 이번 달 기준일까지)을 확인해
EUR, USD는 6자리 값, CNY는 소수 4자리에서 자른 값을 기록하고(급여환율은 각 파일 수식: EUR, USD 올림, CNY 소수 2자리 올림) 메일로 보냄.
EUR은 환율!.xls 급여환율 칸(W96:Y97), USD와 CNY는 급여 폴더 '{YY}년 한국인 급여 정리' xlsx의 '환율' 시트에 기록 (해당 셀과 x-rates 캡처 2장만 바꿈). 그해 파일이 없으면 전년 파일을 복사해 만들고 '(YY년)' 머리글을 바꿈.
x-rates가 기준일까지 반영 안 됐으면 30분 뒤 재시도, 12:00 회차까지 안 되면 알림 메일. 처리 끝난 뒤 회차는 '이미 기록됨'으로 그냥 끝남.
수동: Actions > `급여환율` > Run workflow (날짜 입력, 시험 실행 체크 시 파일, 메일 변경 없음)

## 식대 (새 달 시트)

매월 1일 08:00(칼리닌그라드), 급여 폴더 '식대 정산' xlsx에 그달 시트('26 11월' 형식)를 직전 달 시트 복사로 만든다.
근무일(러시아 생산 달력)마다 1인 750 RUB. 1차(25일 지급분)/2차(다음 달 10일 지급분)는 13~16일 사이에서
구간 합계가 50으로 끝나지 않게(근무일 수 짝수) 나눔. 휴가 등 예외는 메일 받고 직접 수정.

## 제어판 (공지 메일 승인 발송)

제어판: https://claude.ai/artifact/3tU19JPD6u8MoM6PfPaZWr (본인만 열림)

급여환율 기준일에 공지 메일 3통(그룹 EUR, HAS USD, 최경진 부장님 CNY)을 드라이브 '업무 자동화/발송대기/queue.json'에 올린다.
제어판에서 내용을 보고 비밀번호를 넣어 승인하면 confirm 파일이 생기고, 5분마다 도는 `제어판 승인 메일 발송`이
비밀번호(Secret `NOTICE_PASSWORD`)를 서버에서 확인한 뒤 회사 메일 서버(mail.youngsan.com:25, 회사 메일 계정)로 발송한다.
승인 없이는 절대 보내지 않음. 테스트 항목은 3통을 본인(보내는 사람 주소)에게만 [테스트] 제목으로 보냄 (실제 전송 대상도 본인 하나로 고정).

## YSKD 가마감 초안 (ys_gamagam.yml, 수동 실행)
- 입력: 드라이브 'YS 손익보고' 폴더의 전월 '누적 마감_YSKD', '채권_채무_관리_YSKD' (양식), Irina 메일 'отчет КЛД за MM/YYYY' 첨부 2개(monthly, YSH KLD), marina@ 메일 'дебиторка КЛД MM/YYYY' 첨부(1C 채권채무 잔액), CBR EUR 환율
- 출력: 'YYYY년 M월_누적 마감_YSKD.xlsx', 'YYYY년 M월_채권_채무_관리_YSKD.xlsx', 'KLD 재무제표 (RUB) YY년M월.xlsx' - 같은 이름의 자리 파일이 폴더에 미리 있어야 함 (서비스 계정은 파일을 새로 만들 수 없음, 전월 파일 복사로 만들면 됨)
- 누적 마감은 Irina monthly 파일 'KLD 2026' 시트의 월 값을 '26년 실적(RUB)' 같은 행에 그대로 넣음 (ys_gamagam.ROWMAP). 비어 있는 과거 월도 같이 채우고, 이미 값이 있는 과거 월은 안 바꾸고 다르면 메일로 알림
- 채권채무는 Rawdata 행을 1C 파일 그대로 교체, 집계키는 전월 것을 이어받고 신규 행은 '관리대상 외'로 두고 메일로 알림 (판단은 사용자)
- 2026년 10월 사용자 완성본으로 숫자 칸 전부 재현되는 것을 확인함 (비고 문구만 다름)
